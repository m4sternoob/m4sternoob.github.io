About

I'm M4sterNoob, a game programmer in Kitchener-Waterloo, Ontario. BTech in computer science — though I'll admit I learned more from breaking my own physics code at 3 AM than from any lecture.

I built a 3D physics party game in Swift, then immediately thought: cool, now do it in C++ with netcode. That's StumbleGuysClone — pure C++ gameplay, zero Blueprints, because I like knowing exactly what my code is doing.

My rule is simple: finish what I start. A shipped v2.5.0, a playable iOS party game, and this site — all solo.

Looking for: Junior Gameplay, Engine or Tools Programmer roles at Ontario studios. Co-op, internship or full-time — I'm in.
