# M4sterNoob — Portfolio Site

Personal portfolio for M4sterNoob, gameplay and engine programmer (C++, Unreal Engine 5.6, Swift).

Live at https://m4sternoob.github.io/

## What is on the site

- Hero + playable Nokia Snake game tab
- Projects, timeline, and open-source code reviews
- CV section
- Portfolio subpage with project filters, detail modals, and devlog

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000/
```

Static HTML/CSS/JS — no build step. Deployed via GitHub Pages from `main`.
